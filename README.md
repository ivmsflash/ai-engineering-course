# ai-engineering-course
## Troubleshooting

### 'ascii' codec can't encode characters

**Что видел:** ошибка при запуске после того, как вписал неправильный ключ.
**Почему:** в GIGACHAT_CREDENTIALS попали русские буквы, а ключ уходит в
HTTP-заголовок, где допустим только латинский текст.
**Что сделал:** вернул настоящий ключ (латиница + цифры). Заодно убедился, что
благодаря fallback скрипт не упал, а ответил через [HuggingFace].

### timeout или 503

**Что видел:** долгое ожидание ответа провайдера и возврат ошибки.
**Почему:** сеть не доступна (симулировал отсутствие интернета)
**Что сделал:** сеть восстановлена, работа налажена

### 401 Unauthorized
**Что видел:** Ошибка Please use only base64 credentials. Autorization data, not client secret!
**Почему:** умышленно для теста подставил неправильный ключ в GIGACHAT_CREDENTIALS
**Что сделал:** вернул настоящий ключ и проверил работу fallback
